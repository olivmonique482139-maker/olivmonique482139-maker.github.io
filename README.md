# 猫小灶 · 猫咪鲜食订阅互动原型 V4.1

原创中文猫咪鲜食订阅网站。V4 将用户提供的无声猫咪视频重构为全幅沉浸式首屏，并保留 V3 的可编辑套餐、配送安排与三步模拟结算闭环。

长期公网地址：https://olivmonique482139-maker.github.io/

## 启动

最简单的方式：双击项目目录中的 `启动猫小灶网站.cmd`，脚本会在后台启动服务并自动打开浏览器。

也可以在 PowerShell 中手动启动：

```powershell
cd 'D:\CodexProjects\猫咪鲜食订阅网站'
npm start
```

访问 `http://127.0.0.1:4173`。

请勿直接双击 `index.html`；本项目使用 JavaScript 模块与多页面路由，需要通过本地 HTTP 服务运行。

## 页面

- `/`：互动首页
- `/why-us`：鲜食理念、事实对比与产品原则
- `/recipes`：配方目录与蛋白筛选
- `/recipes/chicken` 等：独立配方详情
- `/quiz`：分步定制问卷
- `/plan`：可解释、可拖拽编辑的 10 包推荐结果
- `/cart`、`/checkout`：购物袋与三步模拟结账入口
- `/account`：下一箱、配方、跳过、暂停与取消演示
- `/faq`：帮助中心
- `/policies/privacy`、`/policies/subscription`、`/policies/health`：政策占位页

## V4 首屏体验

- 16:9 猫咪视频全视窗播放，静音循环并可随时暂停
- 用户主动开启的低音量背景音乐，支持循环、淡入淡出与随时关闭
- 桌面端轻量猫爪光标、点击脚印和卡片按压反馈
- 弹窗光标兜底、滚动帧合并与离屏视频自动暂停
- 首页重点图片使用 WebP，并为非首屏图片启用延迟加载与异步解码
- 首屏视频使用 720p 网页优化版本，并保留原始无水印无音频文件
- 手机端点击肉垫反馈，并完整适配“减少动态效果”系统设置
- 透明导航叠加画面，滚动后自动切换为高可读浅色导航
- 首屏直接展示“10 包个性化组合、¥119 起、冷链免运”
- 文案、行动按钮、三步订阅提示与视频画面融为一体
- 桌面端和移动端分别设置画面裁切与渐变遮罩
- 系统开启“减少动态效果”时默认暂停视频并保留封面

## V3 核心闭环

- 活动量与配送周期实时影响建议份量和月均费用
- 可视化 10 格餐盒，支持点击替换与桌面端拖拽配方
- 餐盒数量、配方加价、首箱与续订价格同步更新
- 购物袋展示每一格的口味组成，并可返回重新编辑
- 联系信息、配送日期与时段、订单确认三步结算
- 演示优惠码 `MIAO20`、模拟支付方式与续订知情确认
- 下单成功页包含订单号、配送信息、费用和履约时间轴

## 演示边界

当前仍是前端产品原型，不包含真实数据库、身份认证、库存、营养规则服务、支付、物流、邮件或 CMS。配方、营养、价格、评价、政策和账户状态均为演示内容。正式上线前必须接入服务端权威价格与库存、托管支付字段、订单幂等、敏感健康字段加密、营养与法务审核。
